# 🚀 JS & React Journey

Bem-vindo ao meu repositório de estudos focado no ecossistema JavaScript! 

Este projeto marca uma etapa importante da minha jornada contínua de **365 Dias de Código**. Após consolidar meus conhecimentos em lógica e automações com Python, estou utilizando este espaço para documentar minha transição e evolução rumo ao desenvolvimento Front-end e Mobile com **React** e **React Native**.

## 🎯 Objetivo
O foco principal deste repositório é armazenar a resolução de desafios diários práticos da plataforma [Exercism](https://exercism.org/), construindo uma base sólida em:
- Sintaxe e recursos do JavaScript moderno (ES6+).
- Manipulação de estruturas de dados (arrays, objetos, strings).
- Práticas de Desenvolvimento Guiado por Testes (TDD).

## 🛠️ Tecnologias Utilizadas
- **JavaScript (Node.js):** Linguagem principal dos desafios.
- **Jest:** Framework utilizado para a execução e validação dos testes automatizados.
- **Git / GitHub:** Versionamento de código e documentação da ofensiva diária.

## 📂 Estrutura do Repositório
Os desafios estão organizados em pastas isoladas. Cada pasta representa um projeto independente contendo o código fonte e as suítes de teste.

```text
/javascript
  ├── /hello-world
  │     ├── hello-world.js       # Minha solução

  ├── /desafio-2
  └── /desafio-3
